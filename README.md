# DJ Arbuz

Локальная переозвучка русских фраз **вашей обученной F5-TTS**.

Запуск: дважды нажмите `start.cmd`. Выберите микрофон и наушники/колонки, нажмите **Старт**, произнесите фразу и сделайте паузу. Программа распознаёт текст и воспроизводит его голосом DJ Arbuz. Во время воспроизведения микрофон временно игнорируется, чтобы программа не озвучивала сама себя.

Это работа по завершённым фразам с задержкой, а не непрерывная смена тембра: интонацию создаёт F5-TTS, слова могут содержать ошибки распознавания. Поле текста показывает результат распознавания; в него можно ввести свою фразу и нажать **Озвучить текст**. **Стоп** отменяет ожидающие результаты и останавливает звук; уже начатый расчёт модели завершается в фоне.

Если фразы не определяются, уменьшите порог RMS. Если программа делит предложение раньше времени, увеличьте паузу. 16 шагов синтеза быстрее, 24/32 — больше вычислений. При переполнении очереди новая фраза пропускается с сообщением вместо бесконечного накопления задержки. Лучше говорить по одной фразе и дождаться ответа.

При первом использовании распознавание Whisper small скачивается в `assets/asr`; дальнейшая обработка выполняется на этом компьютере, аудио не отправляется в сервисы. F5 использует CUDA, распознавание — CPU/int8. Выбор выхода позволяет направить речь в установленный виртуальный аудиокабель, но для колонок/наушников он не нужен.

## Что сохранено

- `assets/dj-arbuz/model_last.pt` — полный финальный обучающий checkpoint.
- `assets/dj-arbuz/voice.safetensors` — точные EMA-веса из него для озвучки, без оптимизатора.
- `assets/f5-russian-base` — исходная русская база и словарь.
- `assets/training` — оригинальные записи/тексты, подготовленные WAV, настройки, словарь, конфиги и список старого окружения.
- `assets/vocos` — декодер звука.
- `vendor/f5_tts` — исходный код F5 из прежнего проекта, MIT-лицензия рядом.

F5 checkout: `9c614e9657089213efc6a7421b30630be138a3f5`. Используется архитектура `F5TTS_Base`, а не `F5TTS_v1_Base`. Seed-VC в этой цепочке не используется.

## Установка и проверки

Нужен установленный Python 3.12 x64. В PowerShell запустите `./setup.ps1`. Он создаёт единственное локальное `.venv`, устанавливает CUDA PyTorch и зависимости, экспортирует веса из сохранённого checkpoint. Системные Python не удаляются и не меняются.

`./.venv/Scripts/python.exe tools/smoke.py` проверяет настоящее распознавание и синтез на сохранённой записи, создаёт `output/dj-arbuz-test.wav` и `docs/smoke-result.json`. Микрофон при этой проверке не записывается.

`docs/preserved-assets.json` содержит SHA-256 перенесённых материалов. `docs/voice-export.json` подтверждает точное равенство тензоров экспорта. Старые абсолютные пути в сохранённых обучающих настройках — исторические; рабочий движок разрешает пути относительно нового проекта.

Исходные проекты: [F5-TTS](https://github.com/SWivid/F5-TTS), [faster-whisper](https://github.com/SYSTRAN/faster-whisper).
